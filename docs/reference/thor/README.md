# AYN Thor device reference

> **The PDF is gitignored** (see `.gitignore`); copy it from
> `azahar-thor/reference/manuals/`. Only this README is tracked here.

| file | what |
|---|---|
| `ayn-thor-user-manual.pdf` | AYN Thor user manual - the shipping device |

Useful for the parts of the device that are not the SoC: the button and stick
layout the input mapping targets, the display panel's native resolution and
refresh, thermal/performance mode behaviour, and the storage layout that the
virtual-cartridge scan roots assume.

For the SoC itself see `../snapdragon/` (GPU, kernel) and `../arm/` (CPU cores).
