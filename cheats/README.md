# Cheats

## What is here

- `db/`: the FinalCheat/VitaCheat community database, one `<TITLEID>.psv`
  file per game. 676 files come from <https://github.com/r0ah/vitacheat>
  (commit bb8158a1, 2024-01-06) and `PCSE00899.psv` comes from
  <https://github.com/ShumnoT/VitaCheatDatabase>. The codes are
  user-created and each file names its author in its header comment. The
  source repositories publish no license file. The files were committed on
  the user's decision of 2026-09-17 so that the emulator ships with them and
  users can see which games have cheats before fetching a cartridge from
  storage.
- `index.json`: generated by `python tools/build_cheat_index.py`. One entry
  per file: title, title id, region as written in the file, a region code
  derived from the title id prefix, the game version the codes target, the
  author, and the cheat names. Frontends read this file instead of opening
  every `.psv`. Rebuild it after any change under `db/`.

## Refreshing the database

1. `.\tools\sync_vitacheat_db.ps1 -SkipPush` clones the source repository
   into ignored `tmp/`.
2. Copy `tmp/vitacheat/db/*.psv` over `cheats/db/`.
3. Run `python tools/build_cheat_index.py`.
4. Commit `db/` and `index.json` together. Keep the header comments; they
   carry the author credit.

## How the emulator finds a file

The runtime looks for `<TITLEID>.psv` in the roots listed in
`vita3k/util/src/cheat_paths.cpp`:

- `cheats/<TITLEID>.psv` and `cheats/db/<TITLEID>.psv` next to the emulator
  (this folder for a source checkout)
- the same two paths under the app's shared data folder
- `ux0/vitacheat/db/<TITLEID>.psv` inside the emulated file system
- on Android, common shared-storage and SD-card roots such as
  `/sdcard/cheats/psvita/<TITLEID>.psv`, `/storage/<card>/cheats/psvita/db/`,
  `/storage/<card>/VitaCheat/db/` and `/storage/<card>/Roms/psvita/cheats/`

A game with a matching file shows the Cheats badge in the app list.

## Runtime

The cheat engine is upstream Vita3K's `vita3k/cheat` module (pull request
#4107, cherry-picked on 2026-09-17). It reads these files as they are and
runs the codes once per vblank. Code types `$0 $3 $4 $5 $7 $8 $A $B $C $D`
are handled.

Where the engine looks for a title's file, in order: the user folder
(`<shared data>/cheats/<TITLEID>.psv`), the roots listed above (`db/`, the
SD card, `ux0`), then `cheats/db` next to the desktop executable. A file
found outside the user folder is copied there first. The on/off choices are
saved into that copy as `_V1` markers, so the bundled files are never
modified.

`enable-cheats` in `config.yml` is the master switch.

On desktop, Manage > Cheats or the app list context menu opens the cheat
dialog. On Android, the games grid has a Cheat catalog icon (every game in
the database, search and filters, an In library mark), the long-press menu
of a game with cheats has a Cheats entry, and the pause menu has a Cheats
card. Changes take effect at once while the game runs and at the next boot
otherwise.

On Android the `.psv` files ship inside the APK under `assets/cheats` and
are extracted to `<storage>/cheats/db` on the first launch of each build.

## Tools

- `tools/build_cheat_index.py`: rebuilds `index.json`.
- `tools/convert_vitacheat.py`: converts `.psv` files into JSON for review
  and reports which lines use code types a given engine does not handle.
- `tools/sync_vitacheat_db.ps1`: clones the source repository into `tmp/`
  and, without `-SkipPush`, pushes its `db` folder to the Thor SD card at
  `/storage/2664-21DE/cheats/psvita/db`.

## Rules

- Cheats are for legally owned, offline, single-player games.
- Do not add online cheating, anti-cheat bypasses, DRM bypasses, license
  bypasses, or trainer redistributions.
- Do not remove author headers from the files.
